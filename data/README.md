# data/

Generated by `python scripts/ingest.py`. Do not edit by hand.

| Path | Content |
|---|---|
| `companies.json` | Company list shown in the selector (built from the manifest + structured records) |
| `experiences/<company>_<year>.json` | Validated, source-grounded records (rounds, topics, questions, tips, resources, file + page) |
| `ingestion_manifest.json` | Per-PDF status (indexed / duplicate / failed), content hashes, embedding model + dimension |

These files contain text copied from the PDFs. Commit them only if the interview material may be published.
